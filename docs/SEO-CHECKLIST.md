# Per-Page SEO Checklist — StudyMitra

Use this checklist for every new post or page before publishing.

## Metadata

- [ ] **Title**: `<60 chars`, includes primary keyword, unique per page
- [ ] **Meta description**: `<155 chars`, includes keyword + call-to-action
- [ ] **SEO title** (`seo_title` in DB): Override if default post title isn't optimized
- [ ] **SEO description** (`seo_description` in DB): Override if excerpt is too vague
- [ ] **Canonical URL**: Set via `alternates.canonical` in `generateMetadata`
- [ ] **Open Graph title/description/image**: Added in `generateMetadata`
- [ ] **Twitter card**: `summary_large_image` with title, description, image
- [ ] **robots**: `index: true, follow: true` (unless thin content)

## Structured Data (Auto-handled by SchemaMarkup / FAQSection)

- [ ] **BlogPosting schema**: Auto-injected in `app/blog/[slug]/page.tsx` via `<SchemaMarkup />`
- [ ] **FAQPage schema**: Auto-generated by `<FAQSection />` from extracted FAQ items
- [ ] **BreadcrumbList schema**: Added in every page via `<SchemaMarkup />`
- [ ] **Quiz schema**: Auto-added for mock test posts in blog post page

## Content

- [ ] **Single H1**: Exactly one `<h1>` on the page
- [ ] **H2/H3 hierarchy**: Logical heading structure, no skipping levels
- [ ] **Question-style headings**: Use natural language questions as H2s (e.g., "SSC CGL ki taiyari kaise karein?")
- [ ] **Key takeaway box**: Include a `## सीधा जवाब` or `## Quick answer` block near top of article (rendered as `<KeyTakeaway />`)
- [ ] **FAQ section**: 3–5 real Q&A pairs embedded via `<!--studymitra-faq: [...] -->` comment in markdown content (rendered as `<FAQSection />`)
- [ ] **First 2–3 sentences directly answer the page's primary query**
- [ ] **Minimum 800 words** (Google prefers substantive content)
- [ ] **Bullet lists or tables** for scannable content
- [ ] **No duplicate content** across posts

## Internal Linking

- [ ] **Related posts section**: Auto-added at bottom (latest 4 posts)
- [ ] **Descriptive anchor text**: Use keyword-rich phrases, not "click here" / "read more"
- [ ] **Link to category page**: Each post links to its parent category
- [ ] **Link to 1–2 other relevant posts** within article body

## Images

- [ ] **Use `<Image>` from `next/image`** (not `<img>`)
- [ ] **Width + height attributes** set (no layout shift)
- [ ] **`priority` on LCP image** (typically featured image)
- [ ] **Alt text** describes the image content
- [ ] **`sizes` attribute** for responsive images

## Performance

- [ ] **ISR revalidate** set (60 for blog/category list, 3600 for post detail)
- [ ] **No render-blocking JS** in page content (server components where possible)
- [ ] **Dynamic imports** for heavy client components only

## Verification

- [ ] Run `npm run build` — no errors
- [ ] Check page in Google Rich Results Test (https://search.google.com/test/rich-results)
- [ ] Check page loads with no console errors
- [ ] Verify canonical URL points to correct page
- [ ] Verify sitemap includes the new page (waits for revalidate)
